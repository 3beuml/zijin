## 四份样例

| 文件 | 模拟什么 | 测什么能力 |
| :-- | :-- | :-- |
| `sample-standard.xlsx` | 本学期期中表：22 列、两次次别、数学/英语分层、导师 | 重复列名归组、次别识别、派生列识别 |
| `sample-flat.xlsx` | 最简：单次考试、3 科、单行表头 | 基础路径，不该误报分层 |
| `sample-messy.xlsx` | 3 行合并表头、标题行、末尾合计行、列名带空格 | 表头行数探测、跳过非数据行 |
| `sample-broken.xlsx` | 姓名列表头空、分数是文本、重复行、空行 | 错误路径，必须不崩、给出 warning |

## 自洽性（standard 这份是算好的）

生成时保证内部一致，探测器如果算得对，应该得出：

- `浮动 = 级名1 − 级名`，33/33 成立
- `期中总分 = 语文+数学+英语+物理 分数2` 之和，33/33 成立
- 数学/英语按**层**（1层 = 1A+1B，2层 = 2A+2B）合并排名，层内 0 逆序
- 语文/物理不分层，全体排名

> 注意：样例池内人数只有 17/16，真实数据的池子是**全年级同层**（上百人）。
> 这是刻意的——样例只保证结构真实、数值自洽，不模拟真实池规模。
