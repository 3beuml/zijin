# reference/ —— 参考资料与测试素材

本目录存放**可以公开**的参考资料与测试素材。铁律只有一条：

> **仓库里不许出现任何真实学生数据。**
> 判断法：能用 Ctrl+F 搜到一个真实人名，就不许提交。

本仓库源自一个私有前身项目的重写；其真实数据（花名册、成绩原始件、含名单的截图、
内联了数据的构建产物）**不在本仓库、也不得进入本仓库**。

---

## 一、`samples/` —— 导入测试用的虚构样例

四份 xlsx 全部为**虚构数据**（33 人，常见假名，号段明显虚构）：

| 文件 | 模拟什么 |
| :-- | :-- |
| `sample-standard.xlsx` | 完整期中表格式（两次次别 + 分层 + 导师） |
| `sample-flat.xlsx` | 单次考试、无分层、单行表头（最简格式） |
| `sample-messy.xlsx` | 多行合并表头、列名带空格、多余合计行（压力测试） |
| `sample-broken.xlsx` | 缺姓名列、分数是文本、有重复行（错误路径） |

`_generate.py` 是生成脚本（需要 openpyxl），结果写入同目录。
造假数据时注意：**结构要真，数值可以假**；姓名用固定假名表，
电话用 `13800000001` 这类明显虚构号段。

## 二、`feedback/` —— 使用者反馈

一条一个文件，命名：

```
feedback/2026-11-12-01-成绩导入识别不出分层.md
```

内容只要三行：

```md
原话：<老师说的原话，别改写>
场景：<她当时在干什么>
期望：<她希望看到什么>
```

**原话最重要。** 整理过的需求会丢掉真实痛点，而真实痛点才是判据的来源。
提交反馈前脱敏：去掉真实姓名/学校名，用「某个学生」「某校」代替。
