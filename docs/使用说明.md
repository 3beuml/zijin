# 子衿 · 使用说明

面向中学班主任与导师的本地工作台。成绩导入、学生沟通记录、每周工作手册，
全部数据保存在手机本机；应用不联网、无账号、不上传任何学生数据。

## 安装

1. 从 GitHub 仓库的 Releases 页面下载 APK，传到安卓手机（微信、QQ、数据线均可）。
2. 点开安装。系统提示「未知来源应用」时选择允许——本应用未上架应用商店，属正常提示。
3. 打开「子衿」。数据只存本机；卸载应用会删除本机数据，卸载前先导出备份。

## 首次使用

### 导入成绩表

1. 准备一份成绩表（Excel .xlsx 或 CSV），其中需包含「姓名」列。
2. 点底部中间的 ＋ 键 → 「导入成绩表」，选择文件；
   微信、QQ 里收到的表格文件也可以直接选「用其他应用打开 → 子衿」。
3. 确认页会列出每一列的识别结果，并以表格内真实数据作样例。核对无误后
   给考试命名（如「期中」），点「确认导入」。
4. 一个文件包含多个工作表时，会先列出全部工作表供选择。

识别说明：

- 两次考试同表（如「级名1 / 级名2」）会自动拆成两次考试；上一次考试只保留名次，用于计算浮动。
- 总分一律按科目分数现算，不抄表内总分数值。
- 名次一律带池标签（如「2层内第 5 名」「全年级第 120 名」）。不同科目的名次属于不同的池，不能直接比大小。
- 全角数字、文本数字按数字导入；「缺考 / 旷 / 病假」等标记按缺考处理。
- 重复导入同一次考试：分数被刷新而不是累加；本次表中没有的科目旧分数会一并清除。

### 设置分包

「我的 → 分包」，在下拉框中选择自己的名字（选项来自成绩表中的导师列）。
设置后，学生列表默认只看分包学生，周手册按分包生成；需要时随时切「全班」。

## 日常操作

### 记一笔

今日页有「沟通 / 谈心 / 家访 / 其他」四个按钮，选学生、写内容、保存，
十几秒完成。底部中间的 ＋ 键在任何页面都可以调出同样的入口。
保存后弹层不关闭，可继续给下一位学生记录；多选模式支持一次记给多人
（家长会等场景）。学生详情页也有记录表单，并可填写「跟进」——
保存后自动生成一条关联该学生的待办。

### 待办

「待办」页提供今日 / 本周 / 全部 / 已完成四个视图。
新建待办可设优先级、截止日并关联学生；逾期项红色置顶，可一键顺延；
完成后可撤销。学生详情中的「跟进」字段同样生成待办。

### 考勤与作业

＋ 键 → 「记考勤」：选学生、选类型（迟到 / 早退 / 病假 / 事假 / 旷课 / 离校）、
填时段与原因，保存后可连续给下一位学生记录。
＋ 键 → 「作业登记」：填写日期与科目，全班名单平铺，点按切换
交 / 未交 / 迟交 / 补交 / 免交。学生详情的「作业」卡汇总未交次数，
连续三次未交会标红提醒。

### 搜索与档案

今日页顶部搜索框可同时检索学生、记录内容和待办。
学生详情可编辑档案：性别、宿舍、备注、标签、分包导师。
学生列表支持性别筛选、宿舍与标签筛选、按最近沟通排序。

### 成绩分析

「我的 → 成绩分析」：各科人数与班均、总分前三、每个学生与班均的差、
总分趋势。考试名称与日期可在考试页右上角修改。

## 每周五：周手册

「我的 → 周工作手册」自动生成本周登记表：每个学生一行，含本周沟通 /
谈心 / 家访 / 其他次数、考勤摘要、作业未交次数、最近一次成绩（带池标签）
与本周摘要；无记录的学生以橙色提示。表下方为「下周重点」，
自动带出下周到期的待办。

三个出口：导出 Excel（可直接提交）、A4 页面（独立 HTML，可分享与打印）、
应用内直接打印。数据范围跟随分包设置。

## 数据管理

- **备份**：「我的 → 导出备份 JSON」生成完整备份文件，通过系统分享面板
  发送到微信文件传输助手或保存到任意位置。建议每周一次。
- **恢复**：新手机装好应用后，「我的 → 恢复备份…」选择备份文件即可迁移。
- **快照**：每天首次打开自动保存一份当日快照，保留最近 7 天，可在
  「我的 → 每日快照」中恢复。
- **清空**：「我的 → 数据 → 清空全部数据」，需两次确认。未做过备份或快照
  的数据清空后无法恢复。

## 常见问题

**部分学生显示「未分包」。**
成绩表中导师列内容含空格或写法不一致所致。统一该列写法后重新导入，
同名同班学生自动合并，不会产生重复。

**「浮动」一栏显示 —。**
两次考试的排名池不同（例如分层变动），此情况下不计算名次差值，
属有意设计。

**成绩导错了。**
修正表格后以同一考试名重新导入，分数会被刷新；本次表中没有的科目，
其旧分数一并清除。

**一张表里有多个班级。**
确保「班级」列每行都填写且写法一致（统一用「10班」或统一用「高一(10)班」），
写法不一致会被视为不同班级的学生。

**数据被误清空。**
通过当日快照或备份文件恢复；两者都没有时数据无法找回。
因此建议保持每周导出备份的习惯。

## 维护与构建

```bash
npm install
npm run dev        # 浏览器开发，http://localhost:5173
npm run build      # 产出 dist/
npx vitest run     # 单元测试（135 个）
npx cap sync       # dist 同步至安卓工程
# APK 构建：cd android && gradlew assembleDebug
# 外部验收：node scripts/accept.mjs <导出的备份.json>
```

架构分层：`src/domain/`（纯函数，无 React / DOM）→ `src/ui/`（界面层）→
`src/storage/`（IndexedDB）。设计文档见 `docs/design-data.md` 与
`docs/design-ui.md`，开发过程记录见 `docs/handoff-full.md`。
