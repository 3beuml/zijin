# 子衿 · 使用说明（给班主任 / 导师）

> 一句话：成绩导入、学生沟通记录、每周小结——全在本机，不联网，不上传任何学生数据。

## 安装

1. 把 `子衿-v0.4-debug.apk` 传到安卓手机（微信文件传输 / 数据线都行）。
   （v0.5 的 APK 会在验收通过后重打。）
2. 点开安装。系统提示「未知来源应用」时，选择允许（这是未上架的本地应用）。
3. 打开「子衿」。数据只存在手机本机，删除 App 不影响其他设备，但**会删掉本机数据**——记得先备份。

## v0.6 新增（teacher 需求缺口 P1+P2）

**考勤与作业（班主任刚需，teacher 需求 §5.3.3/§5.3.6）：**

- **记考勤**：＋ 键 → 记考勤 → 选学生 → 迟到/早退/病假/事假/旷课/离校（时段、原因可选）。
  记完不关弹层，可以连着给下一个学生记。学生详情新增「考勤」卡：按类型汇总 + 最近 5 条可删。
- **作业登记**：＋ 键 → 作业登记 → 日期/科目 → 全班名单平铺，默认「交」，
  点一下循环切换 **交 → 未交 → 迟交 → 补交 → 免交**（可只看未交）。
  学生详情「作业」卡显示没交几次，**连续 3 次没交会标红提醒**；
  「我的 → 作业登记」可查看历史、改、删。
- **周手册登记表加「考勤」「作业」两列**（Excel / A4 / 打印同步）——teacher 的登记表格式补齐了。
- 数据结构新增考勤/作业两个实体（v0.5 之前的旧备份恢复时自动补齐，不影响）。

**细节完善（teacher 需求 §5.1/§5.2/§5.4）：**

- 逾期待办多了一个**「顺延」**按钮（不用再进编辑改日期）。
- 记一笔**保存后不关弹层**——接着选下一个学生连着记（家长会场景）；
  选人列表支持**多选模式**，一次记给多个人。
- 学生列表加筛选：**男 / 女**、**按最近沟通排序**；档案里填过宿舍/标签的，还能按宿舍、标签筛。
- 学生详情成绩卡：**3 次考试以上自动画总分趋势折线**（一次考试是数字，三次考试才是故事）。

## v0.5 新增（多角色审查修复版）

**导入更可靠（重点）：**

- **重复导入同一次考试不会再让分数翻倍**——同一文件导两次，分数刷新而不累加；表里没有的旧科目分数会清掉并在报告里说明。
- **支持 CSV 文件**（UTF-8 / Excel 常见的 GBK 编码都能认）；.xls 老格式会明确提示「请另存为 .xlsx」，不再甩英文报错。
- **一个文件里有多个工作表**（比如多个班、多次考试）会先让你选要导入哪一个。
- **年级大表带「班级」列**：每个学生进各自的班；没有名次列时「班内名次」按班现算（之前会算错）。
- **确认导入页**：每列显示表内真实数据样例，照着核对；缺姓名列、分数列没填科目名会被拦下，不能再「碰运气导入」。
- **导入结果**改成可滚动的结果页：新增几人 / 匹配几人 / 写入几行分数一目了然，警告和未导入行完整列出。
- 全角数字（８８）、文本数字（"88.5"）正常导入；「缺考 / 旷 / 病假」等标记按缺考处理并在报告里计数。
- 「道德与法治」这类 App 不认识的科目列**不再被错归到别的科目**——会在确认页提示你填科目名。

**界面更好用（回应使用者反馈）：**

- **输入框全部加大**：记内容最少 4 行、随内容长高；记一笔时显示该生最近几条记录，避免记重。
- 每个弹层右上角都有 **× 关闭钮**，想放弃随时能退。
- **第一次打开**显示「三步开始使用」引导（导入成绩表 → 设置分包 → 记一笔），不再是一片空白加「0/0 全覆盖✓」。
- 学生详情里「上次」考试会注明**只记了名次**，不再让人以为导入失败。
- **考试可以改名、补日期**：成绩分析 → 点进考试 → 右上角「改名 / 补日期」。再也不用对着「本次」猜是哪次考试。
- 底部标签栏加了图标；总分前三改用数字徽标（不再用奖牌 emoji）。
- 文案去掉了程序员黑话（"dock""落库"→"底部中间的 ＋ 键""存入"）。
- 备份恢复时逐条校验数据，坏行直接丢弃，不再让脏数据把界面搞崩。

## v0.4 新增

- **dock 中间的 ＋ 键**：任何页面按 ＋ → 记一笔（沟通/谈心/家访/其他）、新建待办、
  **导入成绩表**——导入不用再翻「我的」，两下就能选文件。
- dock 排列调整为：今日 | 学生 | **＋** | 待办 | 我的；「全部记录」移到「我的」卡片。

## v0.3 新增

- **记录可改可删**：学生详情时间线和「记录」页（底部标签）里每条记录都能改/删——记错日期不再是遗憾。
- **记录页**：全部学生的记录统一时间线，按类型筛选（沟通/谈心/家访…）、按内容搜索。
  「上次跟谁家长聊过手机，哪天来着？」——底部「记录」一搜便知。
- **档案编辑**：学生详情 → 档案卡 → 编辑。性别/宿舍/备注/标签/**分包导师**都能改
  （两份分包名单对不上？直接改导师就行）。不存电话和住址。
- **每日快照**：每天首次打开自动备份一份（保留 7 天），「我的」里可一键恢复——手滑误删能回退。
- **全局搜索**：今日页顶部搜索框，学生/记录/待办一次搜完。
- **成绩分析**：我的 → 成绩分析。各科班均/最高/最低、总分前三、每个学生与班均的差
  （「我的分包 vs 班均」一眼看出谁需要拉一把）。

## 日常四件事

### ⓪ 先设置一次：我是哪位导师

「我的 → 分包」→ 选自己的名字（来自成绩表里的「负责导师」列）。
设置后：学生列表默认只看你的学生，周手册按你的分包生成——这是整个 App 的主视角。
随时可以切「全班」。

### ① 考完试：导入成绩表

「我的 → 导入成绩表」→ 选 .xlsx 文件。
App 会自动识别每一列是什么（姓名/分数/名次/分层…），识别没把握的列会**标黄**——
扫一眼、改不对的，点「确认导入」即可。

- 一张表里有两次考试（如「级名1 / 级名2」）会自动拆成两次考试。
- 上一次考试的分数列不会导入（表里本来就没有），只保留名次用来算「浮动」。
- 总分一律现算，不抄表里的总分数值——这是为了保证总分和四科之和对得上。
- **名次都带池标签**：数学英语按层排的会显示「2层内第 5 名」，语文物理显示「全年级第 120 名」。
  不同科目的名次不能直接比大小，看名次时先看它在哪个池里。

### ② 每天：今日页 + 记一笔

打开 App 就是「今日」：

- **今日待办**：逾期红色置顶，勾选即完成（可撤销）。
- **本周覆盖**：已沟通 x/分包人数，缺谁直接点名，点卡片进学生列表。
- **记一笔**：沟通/谈心/家访/其他 四个按钮 → 选学生（分包优先）→ 写两句 → 保存，全程十几秒。
- **近期重要工作**：未来 7 天的待办。

课间细记：「学生」→ 点学生 →「记一笔」，可以顺手填「跟进」——保存后自动生成一条
关联该学生的待办（如「下周三前回访」），再也不靠脑子记。

### ③ 惦记的事：待办

「待办」页：今日 / 本周 / 全部 / 已完成 四个视图。
新建时可设优先级（高优先级在今日页靠前）、截止日、关联学生。

### ④ 周五：导出周手册

「周手册」→ 自动生成**登记表**：你的每个学生一行——本周沟通/谈心/家访次数、
最近一次成绩（带池名次）、本周摘要；没记录的学生橙色提醒。
下面还有「下周重点」（自动带出下周到期的待办）。

三个出口：**导出 Excel**（直接可交）、**A4 页面**（独立 HTML，可分享可打印）、**打印**。

## 备份与搬家

- 「我的 → 导出备份 JSON」：生成一个备份文件（含学生/成绩/记录/**待办**/分包设置），存到网盘/微信收藏都行。
- 换手机：新手机装好 App → 「我的 → 恢复备份…」→ 选备份文件。
- 建议每周导出一次备份。手机丢了，记录就没了——数据只在你手机上，这是隐私的代价。

## 常见问题

- **导入后有的学生没导师？** 成绩表里「负责导师」列有空格就会这样，详情页看到「未分包」时
  修一下表格再导入一次，同名学生会被合并、不会重复。
- **「浮动」显示 —？** 两次考试的排名池不同（比如分层变了）时不算差值，这是刻意设计。
- **导错了想重来？** 直接把改好的表格再导入一次就行——同一考试名下分数会被刷新，不会重复累加。
  表里删掉的科目旧分数也会一起清掉。
- **表里有多个班级？** 确保「班级」列每行都填了班名（写法要一致：「10班」就都用「10班」，
  别混用「高一(10)班」，否则同一学生会被当成两个人）。
- **误清空了？** 没有恢复就真没了——清空按钮要连点两次才会执行，但备份习惯救一切。

## 给开发/维护者

```bash
npm install
npm run dev        # 浏览器开发，http://localhost:5173
npm run build      # 产出 dist/
npx vitest run     # 单测闸门（135 个）
npx cap sync       # dist → 安卓工程
# APK: cd android && gradlew assembleDebug
# 外部验收: node scripts/accept.mjs <导出的备份.json>
```

架构：`src/domain/`（纯函数，无 React/DOM）→ `src/ui/`（只调 domain）→ `src/storage/`（IndexedDB）。
详读 `AGENTS.md`、`docs/design-data.md`、`docs/handoff-full.md`（各阶段完成记录与偏差都在末尾）。
