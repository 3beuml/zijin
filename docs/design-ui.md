# 界面规范

> 一句话：**名字给气质，界面给效率。**
> 气质只放在主色一个地方，其余全部让给密度和速度。

## 用户与场景

- 中学班主任 / 导师，30–50 岁，单手操作，手机为主（安卓）
- 课间十分钟记一笔；周五晚上导出周手册；考试后导入成绩
- 环境光线差、屏幕小、耐心少

由此推导出三条原则：

1. **信息密度优先**：一屏至少能看到 8–10 个学生
2. **少动效**：≤150ms，只用于状态切换
3. **状态不只靠颜色**：颜色 + 文字/图标，双通道

## 色彩

```css
:root {
  /* 品牌：靛青，取自「青衿」 */
  --indigo-700: #2C4A63;   /* 主色：主按钮、选中态、强调 */
  --indigo-500: #456B85;   /* hover / 次级强调 */
  --indigo-100: #E4EBF0;   /* 选中背景、标签底 */

  /* 纸面 */
  --paper:      #FBF9F5;   /* 页面底色，比纯白护眼 */
  --surface:    #FFFFFF;   /* 卡片 */
  --line:       #E7E2D9;   /* 1px 分隔，替代阴影 */

  /* 文字 */
  --ink-900: #1F2328;      /* 主文字，对比度约 13:1 */
  --ink-600: #5C6166;      /* 次文字 */
  --ink-400: #8C9196;      /* 弱文字：时间戳、占位 */

  /* 语义：只表达「时间与风险」，不做装饰 */
  --success: #2F7D5A;      /* 已完成、已沟通 */
  --warning: #B4731F;      /* 待跟进、本周未联系 */
  --danger:  #A8433A;      /* 逾期、缺失 */
}
```

**不要用 `#2563eb` 那种亮蓝。** 教育产品满街都是，长时间看眼睛累。

语义色一律降饱和。用于小字时注意对比度：`--warning` 对白底约 3.9:1，
只够大号字或图标，正文请改用 `--ink-900` 配文字标签。

## 排版

```css
:root {
  --font-cn: system-ui, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
  --font-num: "IBM Plex Mono", "JetBrains Mono", ui-monospace, monospace;

  --text-xs: 12px;   /* 辅助信息 */
  --text-sm: 14px;   /* 列表行 */
  --text-md: 16px;   /* 正文 */
  --text-lg: 20px;   /* 区块标题 */
  --text-xl: 24px;   /* 页面标题 */

  --lh-body: 1.6;
  --lh-list: 1.4;
  --lh-heading: 1.25;
}
```

**数字一律等宽 + 右对齐：**

```css
.num {
  font-family: var(--font-num);
  font-variant-numeric: tabular-nums;
  text-align: right;
}
```

成绩表 33 行分数，数字不等宽就会左右跳动——这是「看起来不专业」最直接、
改造成本最低的一处。

## 间距与形状

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;

  --radius-control: 6px;
  --radius-card: 10px;

  --row-standard: 56px;
  --row-compact: 48px;
  --touch-min: 48px;      /* 手指目标，勿小于此 */
}
```

**用 1px 边框代替阴影。** 办公工具不要「浮起来」，那会让密集列表变脏。

## 组件规则

### 导航

```
今日  |  学生  |  成绩  |  待办  |  我的
```

- 最多 5 个，已到上限
- 「记录」并入学生详情（它本来就是某个学生的记录）
- 「课表」并入今日（它就是今天的内容）
- 「周手册」放「我的」，或今日页顶部入口

**标签用来分「任务」，不是分「数据表」。**

### 列表

- 行高 56（标准）/ 48（紧凑），默认标准
- 每行最多两行文字：主信息 + 一行状态
- 右侧只放一个操作，多了进详情页
- 成绩表：斑马纹 + 首列冻结 + 数字右对齐

### 卡片

- 现在首页是横向卡片，一屏看不到三个 —— 改成纵向列表
- 卡片只用于「单个强调对象」（如本周覆盖 9/16），不用于罗列

### 按钮

- 主按钮：`--indigo-700` 底 + 白字
- 次按钮：透明底 + `--line` 边框
- 危险操作（清空数据）永远要二次确认，且按钮不用红色填充

## 打印

**A4 打印是重点功能，不是附属。** 老师要交纸质材料。

- 周手册、成绩表都要有打印样式
- 打印时隐藏导航、去背景色、字号按 pt 给（10.5pt 正文）
- 页边距 ≥ 15mm

## 深色模式

**先不做。** 老师白天用，夜间场景是编辑记录不是长读。
等核心流程稳定再考虑，改造成本和收益不匹配。

## 无障碍

- 正文对比度 ≥ 4.5:1
- 触控目标 ≥ 48px
- 正文字号不小于 14px（中年用户，别学互联网 App 用 12px 正文）
- 状态用颜色 + 文字双通道
